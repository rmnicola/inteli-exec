# Formato do relatório de reputação

1. Título e data da pesquisa; o pedido original.
2. Plano de pesquisa: os passos seguidos.
3. Resumo executivo.
4. Uma seção por empresa: porte, reclamações (quantidade, nota, respondidas, resolvidas), temas mais frequentes com trechos, notícias. Cada afirmação com citação numerada [n].
5. Tabela comparativa.
6. Lista de fontes numerada, com o nome exato da empresa em cada página consultada.
